## 2. Mathematical Derivation & Algorithm Specification

### 2.1 Universal Form & Method Q Architecture
Any twin-prime pair $(p, p+2)$ with $p > 3$ satisfies $p = 6m - 1$ and $p + 2 = 6m + 1$.
Method Q constructs a non-linear quadratic candidate manifold:
$$x = S \cdot t$$
$$C = x(x - h)$$
$$A = x^2 - hx - 1, \qquad B = x^2 - hx + 1$$
where $h = 3$ is an odd multiple of 3, $S$ is an odd integer divisible by 3 and composed of prime factors $p_i < 2^{64}$, and $t = 2j + 1$ is an odd search parameter.

### 2.2 Proof Factor Size Dominance
Because $h \ge 3$ and $x > h + 2$:
1. $B - 1 = x^2 - hx = x(x - h) \implies x \mid (B - 1)$.
   Since $B = x^2 - hx + 1 < x^2$, we have:
   $$F = x > \sqrt{B}$$
   satisfying the Pocklington / BLS Theorem 4 size inequality.
2. $A + 1 = x^2 - hx = x(x - h) \implies x \mid (A + 1)$.
   Since $(x - 1)^2 = x^2 - 2x + 1 > x^2 - 3x - 1 = A$, we have:
   $$(F - 1)^2 > A$$
   satisfying the Morrison / BLS Theorem 17 Lucas sequence rank size inequality.

### 2.3 Sieve Mechanics (Tonelli-Shanks Root Solver)
For every sieve prime $q > 3$:
- $A \equiv 0 \pmod q \iff x^2 - hx - 1 \equiv 0 \pmod q \iff (2x - h)^2 \equiv h^2 + 4 \pmod q$.
- $B \equiv 0 \pmod q \iff x^2 - hx + 1 \equiv 0 \pmod q \iff (2x - h)^2 \equiv h^2 - 4 \pmod q$.
The quadratic residues $D_A = h^2 + 4$ and $D_B = h^2 - 4$ are solved via Tonelli-Shanks when Legendre symbols equal 1. Roots $r_x$ are mapped to parameter index $j$:
$$t \equiv r_x \cdot S^{-1} \pmod q \implies j \equiv (t - 1) \cdot 2^{-1} \pmod q$$
All forbidden index classes are eliminated via a segmented bitset sieve over blocks of $j$.
